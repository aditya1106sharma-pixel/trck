# Product docs

How an idea becomes a release in TRCK.

1. **Research** with `/research <idea>`: gaps, market, what to borrow, articles, how to build it free. Saved in `research/`.
2. **PRD** with `/prd <idea>`: the lean 8 section template from pm-execution. Saved in `prds/`, with a status line: Draft, Approved or Shipped.
3. **Build** with `/feature`, check the screens with `/design-check`, then `/review` and `/ship`.

## Plugins these commands use
Installed at user level, not in this repo: pm-skills (`pm-product-discovery`, `pm-market-research`, `pm-execution`) from github.com/phuryn/pm-skills, and Hallmark from github.com/Nutlope/hallmark. A fresh cloud session starts without them: reinstall with the steps in `docs/agent-org-guide.md`.
